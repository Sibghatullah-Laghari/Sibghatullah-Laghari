- Backend: Java 17, Spring Boot 3, Spring Security, JWT filter, OAuth2 Client, Spring JDBC/JPA, Swagger/OpenAPI.
- Frontend and database: React, Vite, Axios, Chart.js, PostgreSQL-oriented SQL schema.
